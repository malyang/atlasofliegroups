# 研究包说明：刚性态射扇上的全局 Hall 量子化

本研究包是在此前 59 页统一稿
《Cocycle-Corrected Hall Multiplication on Rigid Presentation Fans》
基础上的新一轮证明推进。主论文题为：

> **Globalizable Hall Quantisations on Rigid Presentation Fans:  
> Symplectic Wall Transvections, Principal-Coefficient Obstructions,  
> and Universal Kernel Criteria for Cluster-Tilted Algebras**

## 1. 本轮真正补成的缺口

前稿在可变交换矩阵满秩时构造了一个全局 Hall 二余循环；奇异秩时只得到逐腔室修正。本轮证明了任意秩下的精确判据。

设

- `Delta_R` 是极大 rigid 态射对象的 split-index 矩阵；
- `G_R` 是由完整同调恢复的 cluster `g`-矩阵；
- `L_R = G_R Delta_R^{-1}` 是 presentation fan 到 cluster `g`-fan 的局部转移；
- `S` 是主系数量子化的初始 skew 参数。

则一个统一的、contractible-radical 的 exact Hall term-lattice 形式存在，当且仅当

```text
L_R^T S L_R = S
```

对全部可达刚性图表成立。等价地：

```text
Delta_R^T S Delta_R = G_R^T S G_R.
```

所有可全局化参数组成 transfer group 的整数不变格：

```text
Q_global = Skew_n(Z)^{Hol_T}.
```

全局 term 形式被唯一迫使为

```text
D^T S D,   D = (-I  I),
```

对应 Hall 二余循环为

```text
Omega_S = D^T S D - Lambda_Mor.
```

## 2. 任意秩的正面结论

`S=0` 总是不变。因此**标准主系数的可变量子部分在任意秩都存在一个全局 exact-Hall 二余循环**。修正后，同一刚性簇中的可变对象在 Hall 侧交换，与规范主系数量子形式的零 mutable–mutable 块完全一致。

满秩时，若

```text
B_0^T Lambda_0 = d I,
```

则 `Lambda_0` 也被全部 transfer 保持，恢复前稿的 coefficient-free 全局定理。

## 3. 相邻墙变成辛转换

相邻图表的相对转移可写成

```text
T = I + v ell^T,
```

其中 `ell` 是 primitive wall covector，并且

```text
ell^T v = 0.
```

对任意 skew 形式 `S`，论文证明

```text
T^T S T = S   <=>   S v = c ell,  c in Z.
```

因此满秩情形中每条非零墙都是整数辛 transvection。全局化参数格可以只通过边上的这些秩一条件计算。

## 4. 冻结方向的新障碍

“可变部分全局化”与“整个主系数形式在一个固定 frozen basis 中全局化”不是同一件事。

完整 fixed-frozen 全局化除可变不变性外，还必须满足

```text
(Delta_R^T + G_R^T)(d I + S B_0) = 0
```

对所有图表成立。

由此得到：

- 规范主系数 `S=0` 的**可变** Hall cocycle 总能全局化；
- 但完整 fixed-frozen 形式一般不能，因为它要求 `Delta_R = -G_R`；
- 满秩时 `S=Lambda_0` 满足 `dI + Lambda_0 B_0=0`，完整 fixed-frozen 形式反而全局化，此时 frozen 方向中心化。

这给出了“主系数量子种子存在”与“存在一个统一 frozen Hall term lattice”之间的精确差别。

## 5. 不相容 Hall 乘法被化为核包含问题

论文把全部刚性 face algebra 的图表拼成普适余极限 `U_T`，并得到两个满射：

```text
pi_H     : U_T -> twisted exact Hall algebra generated by rigid faces
pi_theta : U_T -> reachable quantum theta algebra
```

一个延拓全部局部图表的全局 Hall-to-theta 代数同态存在，当且仅当

```text
ker(pi_H) subset ker(pi_theta).
```

这没有假装解决不相容扩张，而是把缺口精确缩小成两个关系理想的比较。

## 6. critical Hall 类的识别原理

本轮还证明：未来若能为具体 rigid 态射构造 framed critical/DT 类，只要其积分满足

1. 初始对象归一化；
2. 一步 mutation 协变；

那么它在所有可达 rigid 对象上的积分就被唯一迫使为

```text
theta_{Gamma_T(I(f))}.
```

这不构造 critical 类，但把全局验证缩减为局部变异验证。

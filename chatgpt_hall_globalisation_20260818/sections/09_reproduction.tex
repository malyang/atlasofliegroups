\appendix
\section{Reproduction and implementation notes}
\label{app:reproduction}

The research package contains the master source
\path{globalizable_hall_quantisations.tex}, its section files, the exact
matrix library and two deterministic verifiers.  From the package directory,
run
\begin{verbatim}
./reproduce.sh
\end{verbatim}
The script performs the following steps.
\begin{enumerate}[label=\arabic*.,leftmargin=2.2em]
\item check Python syntax;
\item run \path{verify_A4_globalisation.py}, producing
      \path{A4_globalisation_certificate.json} and
      \path{A4_globalisation_results.tex};
\item run \path{verify_cross_rank_globalisation.py}, producing
      \path{cross_rank_globalisation.json} and
      \path{cross_rank_results.tex};
\item compile the paper with \texttt{latexmk -pdf};
\item build \path{MANIFEST_SHA256.txt} for the source, code, certificates and
      PDF.
\end{enumerate}

\subsection{Code architecture}

\begin{description}[leftmargin=3.4cm,style=nextline]
\item[\path{globalisation_holonomy.py}]
implements skew-symmetric mutation, tropical $C/G$ matrices, paired
presentation/cluster patterns, transfer matrices, invariant skew spaces,
rank-one wall factorization, mutable globalization and full principal block
formulas.

\item[\path{verify_A4_globalisation.py}]
enumerates the complete finite paired $A_4$ pattern, computes the invariant
skew lattice, checks every wall transvection, solves the full fixed-frozen
affine system and writes the macros used in \cref{sec:A4}.

\item[\path{verify_cross_rank_globalisation.py}]
uses deterministic mutation words to test full-rank examples in ranks
$2,4,6$ and singular path matrices in ranks $3,5$.  It separately checks the
canonical mutable statement, the full-rank symplectic statement and the
fixed-frozen obstruction.
\end{description}

\subsection{Exact arithmetic and determinism}

All matrices are SymPy integer or rational matrices.  The code uses no
floating-point comparisons.  Rank-one factorization is checked by exact
reconstruction, invariant forms are obtained from exact nullspaces, and the
full principal parameter locus is solved as an affine rational system before
integrality is checked.  Mutation words in the cross-rank regression are
generated by a fixed integer recurrence; there are no random choices.

The JSON certificates distinguish:
\begin{itemize}[leftmargin=2em]
\item identities proved symbolically in the paper;
\item finite patterns enumerated exhaustively;
\item sampled cross-rank regression evidence;
\item claims not made.
\end{itemize}

\subsection{Independent hand checks}

Several sign-sensitive identities can be checked without running the full
atlas.

First, for the initial morphism chart,
$\Delta_0=-I$ and $G_0=I$, so
\[
 \mathsf L_0=-I,
 \qquad
 \mathsf L_0^TS\mathsf L_0=S
\]
for every skew $S$.

Second, the full principal affine form expands as
\[
 \widetilde\Lambda_R(S)=
 \begin{pmatrix}
  G_R^TSG_R&-G_R^T(dI+SB_0)\\
  (dI-B_0^TS)G_R&dB_0^T+B_0^TSB_0
 \end{pmatrix}.
\]
The quotient-forced global pullback is
\[
 \begin{pmatrix}
  \Delta_R^TS\Delta_R&\Delta_R^T(dI+SB_0)\\
  (-dI+B_0^TS)\Delta_R&dB_0^T+B_0^TSB_0
 \end{pmatrix}.
\]
Comparing these matrices yields exactly the mutable and mixed conditions of
\cref{thm:full-globalization-criterion}.

Third, for a wall transition $T=I+v\ell^T$,
\[
 T^TST-S
 =(Sv)\ell^T-\ell(Sv)^T,
\]
which vanishes exactly when $Sv$ and $\ell$ are proportional.  These checks
are also encoded independently in the verifier.

\subsection{Package integrity}

The build workflow creates a ZIP containing:
\begin{itemize}[leftmargin=2em]
\item the compiled PDF;
\item the modular and expanded single-file TeX sources;
\item all Python code;
\item both JSON certificates and their console outputs;
\item the Chinese README and proof-status audit;
\item the SHA-256 manifest and this reproduction script.
\end{itemize}
The workflow then uploads the ZIP as a build artifact.  The supplied manifest
allows every payload file to be verified after extraction.

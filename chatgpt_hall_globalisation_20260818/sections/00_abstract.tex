\begin{abstract}
Let $A$ be a finite-dimensional algebra, let
$\MM=\Mor(\proj A)$ be the exact category of morphisms between finitely
generated projective right $A$-modules, and assume that a reachable component
of its rigid objects is identified with the cluster pattern of a
cluster-tilted realization.  Put $K=K_0^{\rm sp}(\proj A)$,
$L=K\oplus K$, and let $D(p,q)=q-p$.  For a reachable ordered maximal rigid
object $R$, write $\Delta_R$ for its split-index matrix, $G_R$ for the cluster
$g$-matrix reconstructed from morphism homology, and
$\mathsf L_R=G_R\Delta_R^{-1}$ for the chamber transfer from presentation
weights to cluster $g$-vectors.

We determine exactly which principal quantum parameters can be realized by
one global bicharacter correction of the exact Hall multiplication.  For an
integral skew form $S$ on $K$, a contractible-radical term form with initial
boundary value $S$ exists and restricts to the mutable quantum form in every
rigid chamber if and only if
\[
 \mathsf L_R^TS\mathsf L_R=S
 \qquad\text{for every reachable }R.
\]
The form is then uniquely $D^TSD$, so the globalizable parameters constitute
the integral fixed lattice of the fan-transfer group.  The corresponding Hall
cocycle is $D^TSD-\Lambda_{\MM}$.  In particular, $S=0$ always globalizes,
with no rank assumption; this gives a single global Hall correction for the
canonical principal-coefficient quantization.  If
$B_0^T\Lambda_0=dI$, then $S=\Lambda_0$ is invariant and recovers the
full-rank coefficient-free construction.

Adjacent chamber transfers are shown to be rank-one maps
$T=I+v\ell^T$ with primitive wall covector $\ell$ and $\ell^Tv=0$.  We prove
\[
 T^TST=S \quad\Longleftrightarrow\quad Sv=c\ell
 \quad(c\in\mathbb Z).
\]
Thus, in full rank, the presentation-to-cluster fan map is piecewise integral
symplectic and every nonzero wall map is a symplectic transvection.  We also
solve the stronger fixed-frozen problem: a global form on
$L\oplus K_{\rm fr}$ exists precisely when mutable invariance is supplemented
by
\[
 (\Delta_R^T+G_R^T)(dI+SB_0)=0
 \qquad\text{for all }R.
\]
Consequently the canonical choice $S=0$ generally globalizes only the mutable
part, whereas the full-rank choice $S=\Lambda_0$ globalizes the complete
principal form with central frozen block.

Finally, the rigid chamber algebras are assembled into a universal face
colimit.  A global Hall-to-theta homomorphism extending all chamber maps exists
if and only if the Hall relation kernel is contained in the theta relation
kernel.  This reduces the remaining incompatible-extension problem to a
precise algebraic comparison and yields a mutation-recognition principle for
any future critical Hall construction.  Deterministic exact code verifies the
new identities on all \AIVLabeledStates\ labelled paired seeds and
\AIVChambers\ rigid chambers of the nonhereditary cluster-tilted $A_4$
example, and performs additional full-rank and singular-rank regressions.
\end{abstract}
